# Política de seguridad

No abras un issue público para una vulnerabilidad. Usa **Report a
vulnerability** en la pestaña Security; si no está disponible, contacta de forma
privada a los maintainers. Incluye impacto, reproducción y evidencia sin
secretos ni datos personales innecesarios.

Se confirmará recepción dentro de 72 horas y se hará una evaluación inicial
dentro de 7 días. Hasta nuevo aviso, solo la versión estable más reciente recibe
parches de seguridad.
